Como instalar

How to install

  1. Carrega em “Instalar grátis”Abre a página do Abrigo na Chrome Web Store.
  2. Carrega em “Adicionar ao Chrome”E confirma em Adicionar extensão. No Edge o botão chama-se Obter; se o Edge perguntar, aceita Permitir extensões de outras lojas.
  3. Cria um PINClica no ícone do Abrigo (a peça de puzzle na barra do browser) → Definições → Definir PIN. Sem PIN, qualquer pessoa pode desligar a proteção.
  4. Escolhe o que bloquearConteúdo adulto já vem ligado. Nas definições podes juntar apostas, redes sociais, jogos online e escolher o modo do YouTube.
  1. Click “Install for free”It opens Abrigo's page on the Chrome Web Store.
  2. Click “Add to Chrome”Then confirm with Add extension. In Edge the button is called Get; if Edge asks, accept Allow extensions from other stores.
  3. Set a PINClick the Abrigo icon (the puzzle piece in the browser toolbar) → Settings → Set PIN. Without a PIN, anyone can turn protection off.
  4. Choose what to blockAdult content is on by default. In the settings you can add gambling, social media, online games and pick a YouTube mode.
